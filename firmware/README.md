# dropController V3 firmware

Arduino sketch of the dropController V3, by Martyn Currey (<https://www.dropcontroller.com/>).

- The files in this directory are copied unchanged from the original firmware (version `dC3_AS25006`).
- Martyn Currey has made the dropController V3 fully open source and agreed to include the firmware in this
  repository. The license terms are published on the dropController website; the MIT license of the app in the
  repository root does not apply to these files.
- The messages the firmware exchanges with the app are described in [../docs/PROTOCOL.md](../docs/PROTOCOL.md).
